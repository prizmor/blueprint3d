## Документы

| Документ | Для кого | Содержание |
|---|---|---|
| [manual](manual.ru.md) | пользователи | Полное руководство пользователя: установка, команды, порядок работы, формат спецификации, геометрия, одежда, лист, списки самопроверки, правила, выведенные на практике, ограничения |
| [cli](cli.ru.md) | пользователи, разработчики | Все команды с параметрами, результатами и кодами выхода; переменные окружения |
| [file-formats](file-formats.ru.md) | пользователи, интеграторы | Структура папки объекта, `approved.json`, `bp3d.json`, `report.json`, манифест, `_dynamics.json`, отчёт posetest, кэши |
| [architecture](architecture.ru.md) | разработчики | Компоненты, конвейеры, модель процессов Python ↔ Blender, хеш апрува, системы координат, инварианты, точки расширения |
| [modules](modules.ru.md) | разработчики | Каждый модуль: ответственность, публичный API, зависимости, глобальное состояние, известные проблемы |
| [development](development.ru.md) | контрибьюторы | Настройка, совместимость и правила кода, **правила документации**, как расширять каждую часть, тестирование, версии |
| [../bodies/README.md](../bodies/README.md) | пользователи | Тела в комплекте, их происхождение и лицензия, свои тела |

## Документация обязательна

Изменение инструмента закончено, только когда его описывает документация — на обоих языках, в том же pull request, с записью в `CHANGELOG.md`. CI проверяет минимум, ревью — остальное. Правила: [руководство разработчика → Правила документации](development.ru.md#правила-документации).
